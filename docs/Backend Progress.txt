17. Created baseline_rf.py — RandomForest baseline classifier
	Designed proper experiment structure:
		3-way stratified split: 70% train / 15% val / 15% test
		Stratified on combined (dataset + risk_level) key so UR is represented in all three sets
		5-fold cross-validation on train set only (no test leakage)
	Trained on 3-class risk_level target (low_risk / moderate_risk / high_risk)
		Aligns with the proposal's continuous risk score (not binary fall/no-fall)
	Used class_weight="balanced" to handle 2:2:1 class imbalance
	Evaluated rigorously:
		Validation set as during-development sanity check
		Test set touched only once for final headline numbers
		Per-dataset breakdown (UR vs NTU)
		High-risk recall as primary metric (missed falls = worst failure mode)

20. Created stgcn/ package — Spatio-Temporal Graph Convolutional Network (primary model)
	graph.py        — 14-joint anatomical adjacency matrix (17 bidirectional bones)
	                  normalized as D^(-1/2) (A + I) D^(-1/2)
	model.py        — ST-GCN architecture (1,765,143 trainable parameters)
	                  spatial graph conv → temporal conv (kernel=9) → BN → ReLU → residual
	                  7 ST-GCN blocks + global avg pool + linear classifier
	dataset.py      — PyTorch Dataset that REUSES the baseline split CSVs
	                  (same train/val/test sequences as RF — apples-to-apples comparison)
	train.py        — training loop, Adam + cosine LR, early stopping on val accuracy
	evaluate.py     — final test-set evaluation matching RF baseline metrics

24. Created backend/ package — FastAPI inference service (bridges ST-GCN to frontend)
	data_access.py  — metadata index, sequence_id → .npy resolver
	inference.py    — loads ST-GCN best checkpoint as singleton
	                  softmax → 0–100 continuous risk score
	                  output shaped for frontend's Patient type
	posture.py      — rule-based posture classifier
	                  Lying / Sitting / Standing / Walking
	                  three heuristics: torso inclination, knee-to-hip drop,
	                  ankle horizontal motion (works across UR + NTU coords)
	motion.py       — per-request body tilt, speed, vertical drop,
	                  body height range, confidence
	main.py         — FastAPI app + CORS (allows localhost frontend dev server)
	README.md       — run instructions + curl examples

25. Backend endpoints (4 total)
	GET  /health
		Returns model info + total sequence count
	GET  /api/sequences
		Paginated list of available sequences (filterable by dataset, risk_level)
	GET  /api/sequences/{sequence_id}
		Returns the (100, 14, 3) skeleton data + metadata for animation
	POST /api/predict/{sequence_id}
		Loads sequence, runs ST-GCN + posture + motion, returns full prediction
		Response includes: riskLevel, riskScore (0-100), posture, bodyTilt,
		speed, confidence, softmax probabilities, ground-truth label
