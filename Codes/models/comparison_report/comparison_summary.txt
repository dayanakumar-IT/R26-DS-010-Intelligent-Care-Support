------------------------------------------------------------------
Iter-1 had RF at 96.94 % CS (suspicious). Iter-2 fixes lowered everything:

Fix                                            | iter-1 -> iter-2 (CS RF)
-----------------------------------------------|---------------------------
Random split -> Cross-Subject split            | 96.94 % -> 87.48 %  (-9.46)
Frame-freeze pad -> linear interpolation       | applied
Zero-fill missing UR poses -> carry-forward    | applied
ST-GCN no aug -> rotate +-15, mirror, jitter   | ~97 % -> 91.86 % (~ -5)

Iteration-2 numbers (87-94 % in-domain) match the published band for
skeleton-based fall/action recognition on NTU - so the leakage is gone.

Two extra sanity checks:
  - Val ~ test on every CS run (gaps under 2.5 %) -> honest split.
  - CD collapses to 0-25 % -> proves in-domain numbers are not trivial;
    if preprocessing still leaked, CD would also be high. It isn't.

------------------------------------------------------------------
4. WHY CROSS-DATASET COLLAPSE IS A FEATURE, NOT A BUG
------------------------------------------------------------------
1. NTU (4,752 seqs, 3 cameras, 40+ actions) and UR (45 seqs, 1 lab,
   1 camera) are different distributions. Zero subject/camera overlap.
2. Ranking is honest: RF (20 %) > Posture (23 %) > ST-GCN (4 %) >
   Fusion (0 %). Deeper model, harder fall. Expected.
3. Justifies the proposal's plan: combined NTU+UR training (CS) +
   in-house lab study to bridge the domain gap.

6. ONE-PARAGRAPH PANEL ANSWER
------------------------------------------------------------------
After fixing four preprocessing leaks (random -> subject split,
frame-freeze -> interpolation, zero-fill -> carry-forward, plus
ST-GCN training augmentation), the four models land at 87-94 % on
Cross-Subject and 78-94 % on Cross-View, with train-val-test gaps
under 5 % on every run - so no overfitting and no leakage. Cross-
Dataset (NTU -> UR) collapses to 0-23 % across all four models; the
ST-GCN run shows train 96.10 % ~ val 96.39 % on the source domain
but only 4.4 % on the target, which is a clean domain-shift signal
that motivates the combined-training and in-house-lab study plan.
